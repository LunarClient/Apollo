# Private Modules

Apollo has private modules and private features, which are access restricted parts of the API.

- A **private module** is restricted as a whole, such as the Cosmetic module.
- A **private feature** is a restricted part of an otherwise public module, such as the Mod Status API of the Mod Setting module. The rest of that module stays public.

In the Apollo API, private modules and features are marked with the `@RestrictedAccess` annotation. Access is granted separately for each private module and feature.

These modules and features are only available on pre-approved servers and will not work on servers that have not received approval. They are still subject to our [Acceptable Use](/apollo/acceptable-use) guidelines.

### How to Request Access

We are not currently granting broad access to private modules and features. However, if you have a specific use-case in mind, you may request access by contacting **apollo@lunarclient.com**.

Please include:
- Your server name & domain
- The private modules and features you need
- A description of your use-case
- Any relevant code snippets (if applicable)
