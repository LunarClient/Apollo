# Nick Hider

Allows you to hide skins and usernames for yourself or others.

## Integration

### How to toggle the mod

```java
public void toggleNickHiderExample(Player viewer, boolean value) {
    Optional<ApolloPlayer> apolloPlayerOpt = Apollo.getPlayerManager().getPlayer(viewer.getUniqueId());
    apolloPlayerOpt.ifPresent(apolloPlayer -> this.modSettingModule.getOptions().set(apolloPlayer, ModNickHider.ENABLED, value));
}
```

## Available options

- __`ENABLED`__
    - Config Key: `enabled`
    - Values
        - Type: `Boolean`
        - Default: `false`

- __`HIDE_NAME`__
    - Replaces your Hypixel nick with your real name, or with your Nickname when Hide Your Real Name is on
    - Config Key: `hide-name`
    - Values
        - Type: `Boolean`
        - Default: `true`

- __`HIDE_REAL_NAME`__
    - Replaces your real name with your Nickname
    - Config Key: `hide-real-name`
    - Values
        - Type: `Boolean`
        - Default: `true`

- __`HIDE_OTHERS_NAMES`__
    - Replaces the names of other players with the Hidden Player Prefix and a number
    - Config Key: `hide-others-names`
    - Values
        - Type: `Boolean`
        - Default: `false`

- __`CUSTOM_SUFFIX`__
    - Shows every hidden player as the prefix followed by the Hidden Player Suffix, instead of numbering them
    - Config Key: `custom-suffix`
    - Values
        - Type: `Boolean`
        - Default: `false`

- __`HIDE_LOBBY_ID`__
    - Config Key: `hide-lobby-i-d`
    - Values
        - Type: `Boolean`
        - Default: `false`

- __`HIDE_OWN_SKIN`__
    - Shows you as Steve or Alex, or with a set skin from another player
    - Config Key: `hide-own-skin`
    - Values
        - Type: `Boolean`
        - Default: `false`

- __`USE_REAL_SKIN`__
    - Shows your own skin even when a server changes it, for example with a Hypixel nick
    - Config Key: `use-real-skin`
    - Values
        - Type: `Boolean`
        - Default: `true`

- __`HIDE_OTHERS_SKIN`__
    - Shows other players as Steve or Alex
    - Config Key: `hide-others-skin`
    - Values
        - Type: `Boolean`
        - Default: `false`
